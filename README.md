### 📋 Descripción del Proyecto
Trabajo final para el Diplomado de **Data Science y Business Intelligence**. El objetivo es desarrollar un modelo de Deep Learning capaz de predecir el incumplimiento de pago (Default) y la deserción de clientes (Churn) utilizando una base de datos sintética de 10,000 clientes.

### 🛠️ Tecnologías Utilizadas
* **Lenguaje:** Python
* **Deep Learning:** TensorFlow / Keras (Redes Neuronales, LSTM, Dropout, Regularización L1/L2)
* **Análisis de Datos:** Pandas, NumPy, Scikit-Learn (Factor Analysis, K-Means)
* **Visualización:** Matplotlib, Seaborn

### 🔍 Resultados Clave
1.  **Detección de Overfitting:** Se implementaron técnicas de regularización (Dropout 30%, L1/L2) y Early Stopping para garantizar la estabilidad del modelo.
2.  **Segmentación de Clientes:** Se identificaron 4 perfiles psicométricos (Vulnerables, Estables, Alto Riesgo, VIPs) mediante algoritmos no supervisados.
3.  **Política de Riesgo:** Se diseñó una estrategia automatizada de asignación de líneas de crédito basada en las predicciones del modelo.
